# 표준 NDA(비밀유지계약서) 가이드

## 필수 포함 조항 체크리스트

### 1. 비밀정보의 정의
- 명확하고 한정적으로 정의 (포괄적 정의는 분쟁 원인)
- 예시:
  - 기술 도면, 소스코드, 알고리즘
  - 고객 정보, 가격 정책, 사업 전략
  - "비밀" 또는 "Confidential" 표시된 문서
- **제외 항목 명시 필수**:
  1. 공개 도메인의 정보
  2. 수령 전 이미 보유하고 있던 정보
  3. 제3자로부터 적법하게 취득한 정보
  4. 법령 또는 정부 기관의 요청에 의해 공개되는 정보
  5. 독자적으로 개발한 정보

### 2. 비밀유지 의무 내용
- 비밀정보를 제3자에게 공개하지 않을 의무
- 계약 목적 이외의 용도로 사용하지 않을 의무
- 내부 접근 권한 제한 및 보안 조치 유지 의무

### 3. 유효기간
- **권고**: 계약 체결 후 또는 비밀정보 수령 후 2~5년
- 영구 유효기간은 공서양속 위반 가능성
- 영업비밀보호법상 영업비밀은 별도 보호

### 4. 정보의 반환/파기
- 계약 종료 시 비밀정보 매체 반환 또는 파기 절차 명시
- 파기 확인서 발급 요청 가능 여부

### 5. 손해배상 및 구제수단
- 위반 시 실손해 배상 원칙
- **주의**: 과도한 위약벌(손해와 무관한 고액 배상)은 법원에서 감액 가능
- 금지청구(가처분) 가능 여부 명시

## 표준 NDA 조항 예시

```
제1조 (비밀정보의 정의)
"비밀정보"란 일방 당사자("제공자")가 타방 당사자("수령자")에게 서면, 구두 또는 
전자적 방법으로 제공하는 정보 중 "비밀" 또는 "Confidential"로 표시되거나, 
제공 당시 비밀임을 구두로 고지하고 14일 이내에 서면으로 확인된 정보를 말한다.
단, 다음 각 호의 정보는 비밀정보에서 제외한다:
(1) 수령 시 이미 공지된 정보 또는 수령 후 수령자의 귀책 없이 공지된 정보
(2) 수령 전에 수령자가 합법적으로 보유하고 있던 정보
(3) 관련 법령에 의해 공개가 강제된 정보

제2조 (비밀유지 의무)
수령자는 비밀정보를 계약 목적 이외의 용도로 사용하거나 제3자에게 공개하여서는 
아니 되며, 자신의 직원 중 필요한 자에 한하여 제한적으로 공개할 수 있다.

제3조 (유효기간)
본 계약에 따른 비밀유지 의무는 계약 체결일로부터 3년간 유효하다.

제4조 (손해배상)
수령자가 비밀유지 의무를 위반할 경우 제공자에게 발생한 실제 손해를 배상한다.
위약벌은 별도로 정하지 않는다.
```

## NDA 검토 시 주요 위험 포인트

| 위험 항목 | 내용 | 권고 조치 |
|---|---|---|
| 비밀정보 범위 과도 | 모든 정보를 비밀로 지정 | 구체적 정의 + 제외항목 추가 |
| 영구 유효기간 | 계약 종료 후에도 무기한 의무 | 2~5년으로 한정 |
| 과도한 위약벌 | 실손해 수십 배 배상 조항 | 실손해 배상으로 변경 |
| 일방적 의무 | 수령자만 의무, 제공자 면책 | 상호 의무로 수정 |
| 공개예외 누락 | 법령 공개 강제 시 면책 없음 | 법령 공개 예외 조항 추가 |
