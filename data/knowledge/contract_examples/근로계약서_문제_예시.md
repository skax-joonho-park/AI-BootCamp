# 근로계약서 문제 조항 예시 및 수정 방향

## 예시 1: 포괄임금제 위험 조항

### 문제 조항
```
제5조 (임금)
월 급여 300만 원(연장·야간·휴일 근로수당 포함)으로 하며, 
초과근무에 대한 별도 수당은 지급하지 아니한다.
```

### 위험 포인트
- 각 수당 항목 및 금액 명세 없음
- "별도 수당 미지급" 명시는 근기법 위반 가능
- 실제 연장근로가 월 52시간을 초과할 경우 추가 청구 가능

### 수정 방향
```
제5조 (임금)
① 기본급: 월 250만 원
② 연장근로수당(월 20시간 기준): 월 34만 원
③ 야간근로수당(해당 시 실비): 별도 정산
④ 위 ②항의 기준 초과 연장근로 발생 시 추가 정산
```

## 예시 2: 과도한 경업금지 조항

### 문제 조항
```
제12조 (경업금지)
근로자는 퇴직 후 5년간 국내외 동종업계에 취업하거나 
동종 사업을 영위할 수 없으며, 위반 시 손해배상으로 
5억 원을 지급한다.
```

### 위험 포인트
- 5년은 과도 (법원 1년 초과 시 감축 가능성 높음)
- "국내외 전면" 제한은 직업선택 자유 과도 침해
- 5억 위약벌은 실손해와 무관하여 법원 감액 가능
- 대상 보상 없음 → 유효성 더욱 약화

### 수정 방향
```
제12조 (경업금지)
① 근로자는 퇴직 후 1년간 직접 경쟁 관계에 있는 
   국내 동종 기업에 동일 직무로 취업하지 않는다.
② 본 조항의 대가로 퇴직 시 ○개월 급여 상당액을 지급한다.
③ 위반 시 실제 발생한 손해액을 배상한다.
```

## 예시 3: 일방적 불이익 조항 모음

### 문제 조항들
```
- "회사의 경영 판단에 따라 업무, 근무지, 직급을 변경할 수 있다."
- "수습 기간(3개월) 중 임금의 80%를 지급하며, 해고예고 없이 계약 해지 가능."
- "근로자 귀책으로 인한 손해는 급여에서 공제할 수 있다."
```

### 위험 포인트
- 포괄적 전보명령: 생활상 불이익·업무상 필요성 없으면 부당
- 수습 중 해고: 3개월 이상 수습은 해고예고 대상 (단, 3개월 미만은 예외)
- 급여 공제: 법원 판결 없이 일방적 공제는 임금체불

### 수정 방향
- 전보·전직은 "합리적 업무상 필요와 사전 협의" 조건 추가
- 수습 기간 해고는 "정당한 이유 서면 통보" 조건 명시
- 손해배상은 급여 공제 방식 삭제, 별도 소 제기로 청구

## 계약서 서명 전 최종 확인사항

1. 임금 명세(기본급·수당 항목·금액)가 구체적으로 기재되어 있는가?
2. 포괄임금제 적용 시 세부 내역이 명시되어 있는가?
3. 경업금지 기간·범위·보상이 합리적인가?
4. 해고 절차가 근로기준법 기준에 부합하는가?
5. 계약서 2부 작성 후 쌍방 서명·교부가 이루어지는가?
6. 서명 전 충분한 검토 시간이 주어지는가?
